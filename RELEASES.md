# Release Notes

## Version 1.0.0 - First Release

### Overview
Aero Browser Android application - first public release. This marks the initial release of the Android version of Aero Browser, a privacy-first web browser.

### Features
- Tabbed browsing with normal and private modes
- Homepage configuration and startup page support
- Bookmark management
- Download handling
- History tracking and viewing
- Settings panel with various privacy and security options
- Address bar with URL completion (Ctrl+Enter)
- Vertical tab support
- Split-screen view
- Fingerprint protection and canvas/WebGL randomization
- Global Privacy Control (GPC) support
- HTTPS enforcement
- Cookie isolation
- Fire button to clear all data
- Tracking protection modes (Standard/Aggressive/Off)
- DNT (Do Not Track) support
- Site permissions management
- Password generation and storage
- Theme customization (light/dark)
- Custom titlebar with window controls

### Technical
- Built with Kotlin and Jetpack Compose/Hilt
- Room database for local storage
- Coroutines for asynchronous operations
- Dependency injection with Hilt
- Material Design 3 theming
- Background tab throttling and sleeping tabs support

### Known Issues
- Initial release, no known issues

### Upgrade Notes
- This is the first release, so there are no upgrading instructions
- Profile data from previous versions is not applicable
